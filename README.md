# Emergency Service Management System

## About the Project
A C++ program designed to organize emergency service requests and maintain basic information about emergencies.

## Features
- Register emergency requests
- Display emergency records
- Organize requests by priority, if implemented
- Search for emergency information
- Manage request records

## Technologies Used
- C++
- Data Structures

## Concepts Used
Queues, priority queues, functions, classes, and conditional statements, depending on implementation.

## How to Run
Compile and run the C++ source file using a compatible compiler.

## Learning Objective
To understand how data structures can help organize emergency requests.
